#==============================

# 1. Assignment: Assigns the value 5 directly to variable x
x = 5

# 2. Addition assignment: Adds 3 to x (x becomes 8)
x += 3  # Equivalent to: x = x + 3

# 3. Subtraction assignment: Subtracts 3 from x (x becomes 5)
x -= 3  # Equivalent to: x = x - 3

# 4. Multiplication assignment: Multiplies x by 3 (x becomes 15)
x *= 3  # Equivalent to: x = x * 3

# 5. Division assignment: Divides x by 3, always returns a float (x becomes 5.0)
x /= 3  # Equivalent to: x = x / 3

# 6. Modulo assignment: Divides x by 3 and assigns the remainder (5.0 % 3 is 2.0)
x %= 3  # Equivalent to: x = x % 3

# 7. Floor division assignment: Divides x by 3 and rounds down to whole number (2.0 // 3 is 0.0)
x //= 3  # Equivalent to: x = x // 3

# 8. Exponentiation assignment: Raises x to the power of 3 (0.0 ** 3 is 0.0)
# (Resetting x to 2 for a better example: 2 ** 3 = 8)
x = 2
x **= 3  # Equivalent to: x = x ** 3

# 9. Bitwise AND assignment: Performs binary AND on x and 3 (Binary: 1000 & 0011 = 0000)
x &= 3  # Equivalent to: x = x & 3

# 10. Bitwise OR assignment: Performs binary OR on x and 3 (Binary: 0000 | 0011 = 0011)
x |= 3  # Equivalent to: x = x | 3

# 11. Bitwise XOR assignment: Performs binary XOR on x and 3 (Binary: 0011 ^ 0011 = 0000)
x ^= 3  # Equivalent to: x = x ^ 3

# 12. Bitwise right shift assignment: Shifts x's binary bits 3 places to the right
# (Resetting x to 8 for a better example: 1000 shifted right by 3 is 0001)
x = 8
x >>= 3  # Equivalent to: x = x >> 3

# 13. Bitwise left shift assignment: Shifts x's binary bits 3 places to the left (1 shifted left by 3 is 8)
x <<= 3  # Equivalent to: x = x << 3

# 14. Walrus operator (Assignment Expression): Assigns 3 to x AND immediately returns the value
# to be used inside another expression (like print, an if-statement, or a loop)
print(x := 3)  # Assigns x = 3, then prints 3

#============================== 

x = 5  # Binary: 0101
y = 3  # Binary: 0011

# 1. Bitwise AND (&): Compares each bit; sets to 1 only if BOTH bits are 1
# 0101 & 0011 = 0001 (Decimal: 1)
result_and = x & y

# 2. Bitwise OR (|): Compares each bit; sets to 1 if AT LEAST ONE of the bits is 1
# 0101 | 0011 = 0111 (Decimal: 7)
result_or = x | y

# 3. Bitwise XOR (^): Compares each bit; sets to 1 if ONLY ONE of the bits is 1 (not both)
# 0101 ^ 0011 = 0110 (Decimal: 6)
result_xor = x ^ y

# 4. Bitwise NOT (~): Inverts all bits (1 becomes 0, 0 becomes 1). 
# Due to how computers store negative numbers (Two's Complement), it effectively returns -(x + 1)
# ~0101 becomes ...11111010 (Decimal: -6)
result_not = ~x

# 5. Zero fill left shift (<<): Shifts bits to the left by 2 spaces, pushing zeros in from the right
# 0101 shifted left by 2 becomes 010100 (Decimal: 20)
# (Shortcut: Effectively multiplies the number by 2 for each shift)
result_left = x << 2

# 6. Signed right shift (>>): Shifts bits to the right by 2 spaces, discarding bits on the right
# 0101 shifted right by 2 becomes 0001 (Decimal: 1)
# (Shortcut: Effectively performs floor division by 2 for each shift)
result_right = x >> 2


#============================== 

# 1. Parentheses () - Forces addition before multiplication
print((100 + 5) * 3)  # 105 * 3 -> 315

# 2. Exponentiation ** - Power happens before addition
print(100 + 2 ** 3)  # 100 + 8 -> 108

# 3. Unary operators (-x) - Negative sign applies before addition
print(100 + -5)  # 100 - 5 -> 95

# 4. Multiplication/Division/Modulo (*, /, //, %) - Multiplication happens first
print(100 + 5 * 3)  # 100 + 15 -> 115

# 5. Addition/Subtraction (+, -) - Evaluates left-to-right
print(100 - 5 + 3)  # 95 + 3 -> 98

# 6. Bitwise Shifts (<<, >>) - Addition happens before shifting bits
print(1 + 1 << 2)  # 2 << 2 -> 8

# 7. Bitwise AND (&) - Addition happens before bitwise AND
print(7 & 2 + 1)  # 7 & 3 -> 3

# 8. Bitwise XOR (^) - Bitwise AND happens before bitwise XOR
print(5 ^ 4 & 3)  # 5 ^ 0 -> 5

# 9. Bitwise OR (|) - Bitwise XOR happens before bitwise OR
print(1 | 4 ^ 4)  # 1 | 0 -> 1

# 10. Comparisons (==, !=, etc.) - Addition happens before comparison
print(100 + 5 == 105)  # 105 == 105 -> True

# 11. Logical NOT (not) - Comparison happens before 'not'
print(not 100 > 200)  # not False -> True

# 12. Logical AND (and) - 'and' happens before 'or'
print(True or True and False)  # True or False -> True

# 13. Logical OR (or) - Evaluated last in the expression
print(False or True)  # True

***Python Collections (Arrays)***
There are four collection data types in the Python programming language:

List is a collection which is ordered and changeable. Allows duplicate members.
Tuple is a collection which is ordered and unchangeable. Allows duplicate members.
Set is a collection which is unordered, unchangeable*, and unindexed. No duplicate members.
Dictionary is a collection which is ordered** and changeable. No duplicate members.

Python - Join Sets

Join Sets
There are several ways to join two or more sets in Python.
The union() and update() methods joins all items from both sets.
The intersection() method keeps ONLY the duplicates.
The difference() method keeps the items from the first set that are not in the other set(s).
The symmetric_difference() method keeps all items EXCEPT the duplicates.

#Example: union()
set1 = {"a", "b", "c"}
set2 = {1, 2, 3}

set3 = set1.union(set2)
print(set3)

Result:
{1, 2, 'b', 3, 'c', 'a'}
